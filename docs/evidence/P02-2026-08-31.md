## Residual risks

- MATLAB parser/runtime compatibility, `validateattributes` error identifiers, graphics rendering,
  callback behavior (including model-handle retention and P02-only cleanup), and exact seeded numerical
  results remain unverified without the named runtime.
- The forbidden root MATLAB harness does not independently reject scaffold status before calling a
  retained `run_checks.m`; it also resolves generic `model`, `interactive`, and `run_checks` names and
  removes module paths on cleanup. From a different module current folder it can dispatch the wrong
  check, and a still-open P01 UI can lose its model binding after P02 launch. P02 captures its own UI
  model handle, but the cross-module harness requires a separately authorized repair.
- Static checks cannot establish educational effectiveness or confirm that a learner interprets density
  area, tail accounting, and unequal-width bins correctly.
- Fixed interactive edges at plus/minus four generating standard deviations intentionally expose rare
  tails; counts are visible, but correct learner interpretation still requires the tutor prompts.
- Atomic replace and lock contention/concurrency were exercised on Linux/Python 3.11. Windows locking,
  actual process-kill/power-loss behavior, and filesystem durability beyond file `fsync` were not tested.
- The lock retry path treats any acquisition `OSError` as transient contention; an unsupported-lock
  filesystem could therefore report a timeout as "busy" instead of exposing the underlying capability error.
- Canonical control `batches/P02.yaml` names `kpbianco/portfolio-control`, while the approved active
  batch, automation metadata, and actual remote use `tranquilWorks/portfolio-control`. Scope and
  acceptance agree; this upstream ownership-name drift is outside P02's allowed paths.
- P02-specific remote Portfolio Control validation and the target Quality workflow did not run because
  no commit, push, or pull request was authorized. Their governing-revision/baseline-main runs were
  inspected separately; they are not P02 validation.
