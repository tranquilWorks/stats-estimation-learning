# Start here

This is the Probability, Statistics, Estimation, and Detection interactive MATLAB track. Run
`./bin/learn status`, then `./bin/learn start`. P01 is the reference slice; later modules advance in
canonical order through one-to-one Portfolio Control batches. A learner session follows read →
visualize → move one lever → visualize the change → read/explain, then a broken case, checks, and
teach-back. Use `./bin/learn list` for the current implementation frontier.

Use `docs/CURRICULUM_AUDIT.md` for the complete phase and batch map.
